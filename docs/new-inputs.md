# Adapting Gleaner To New Inputs

This guide documents the two reusable input paths supported by this artifact. Both paths end in the RCAbench Platform v2 layout under `DATA_ROOT`, which defaults to `data/rcabench-platform-v2` unless overridden.

Use a scratch `DATA_ROOT` while testing conversions so committed fixture data is not overwritten:

```bash
export DATA_ROOT=temp/reuse-data
export OUTPUT_ROOT=temp/reuse-output
```

## Target Dataset Layout

A converted dataset is stored as:

```text
$DATA_ROOT/
  data/<dataset>/<datapack>/
    normal_traces.parquet
    abnormal_traces.parquet
    normal_logs.parquet
    abnormal_logs.parquet
    normal_metrics.parquet
    abnormal_metrics.parquet
    normal_metrics_sum.parquet
    abnormal_metrics_sum.parquet
    normal_metrics_histogram.parquet
    abnormal_metrics_histogram.parquet
    metrics_sli.parquet                 # generated by sampler commands when needed
    env.json
    injection.json
    conclusion.parquet                  # raw detector output converted from conclusion.csv when available
  meta/<dataset>/
    index.parquet
    labels.parquet
    attributes.parquet                  # for RCABench-style raw input after make_rcabench scan
```

Trace parquet files use at least:

```text
time, trace_id, span_id, parent_span_id, service_name, span_name, duration, attr.*
```

Log parquet files use at least:

```text
time, trace_id, span_id, service_name, level, message, attr.*
```

Metric parquet files use at least:

```text
time, metric, value, service_name, attr.*
```

## Path A: TracePicker Trace-Only Input

Use this path for legacy TracePicker data where each datapack has only `traces_spans.csv`. The local fixture is `data/tracepicker/sockshop/traces_spans.csv`.

### Input Contract

```text
data/tracepicker/<datapack>/traces_spans.csv
```

Expected CSV columns:

```text
traceID, spanId, parentSpanId, startTime, duration, statusCode, service, operation, instance
```

`make_tracepicker.py` converts this trace-only input to the platform layout by:

- mapping timestamps from microseconds to UTC datetimes;
- mapping TracePicker span/service columns to RCAbench span columns;
- writing all spans to `normal_traces.parquet`;
- writing empty abnormal traces, logs, and metrics with compatible schemas;
- writing a normal-only label and minimal `env.json`, `injection.json`, and `k8s.json`.

Because this path has no true abnormal window, logs, alarms, or RCA labels, use it for trace-only sampler tests and cross-system input-shape checks. For Gleaner, prefer no-log/no-alarm variants such as `gleaner_no_logs_no_ad`.

### Local Smoke Test

```bash
uv run python make_tracepicker.py local-test
```

This reads `data/tracepicker/sockshop/traces_spans.csv` and prints converted columns, trace counts, and service distribution.

### Convert TracePicker Data

```bash
DATA_ROOT=temp/tracepicker-platform \
uv run python make_tracepicker.py run \
  --src-folder data/tracepicker \
  --dataset-name tracepicker
```

Expected outputs:

```text
temp/tracepicker-platform/data/tracepicker/sockshop/normal_traces.parquet
temp/tracepicker-platform/meta/tracepicker/index.parquet
temp/tracepicker-platform/meta/tracepicker/labels.parquet
```

### Run A Trace-Only Sampler Check

```bash
DATA_ROOT=temp/tracepicker-platform \
OUTPUT_ROOT=temp/tracepicker-output \
uv run python scripts/full/platform_cli.py sample single \
  random tracepicker sockshop \
  --sampling-rate 0.1 \
  --mode offline \
  --clear
```

For Gleaner trace-only adaptation, replace `random` with `gleaner_no_logs_no_ad` after confirming the converted trace schema contains the fields the variant expects.

## Path B: Raw RCABench / ClickHouse OpenTelemetry Input

Use this path for raw OpenTelemetry-style data exported from ClickHouse. The local fixture is:

```text
data/rcabench_dataset/ts9-ts-basic-service-response-delay-hfvbg6/
```

The fixture includes raw normal/abnormal traces, logs, metrics, `env.json`, `injection.json`, `k8s.json`, `conclusion.csv`, and a shared Drain3 template state under `data/rcabench_dataset/drain_template/`.

### Input Contract

Each datapack directory under `data/rcabench_dataset/` should contain:

```text
normal_traces.parquet
abnormal_traces.parquet
normal_logs.parquet
abnormal_logs.parquet
normal_metrics.parquet
abnormal_metrics.parquet
normal_metrics_sum.parquet
abnormal_metrics_sum.parquet
normal_metrics_histogram.parquet
abnormal_metrics_histogram.parquet
env.json
injection.json
k8s.json
conclusion.csv
```

The platform converter reads raw ClickHouse-style columns such as `Timestamp`, `TraceId`, `SpanId`, `ParentSpanId`, `SpanName`, `ServiceName`, `Duration`, `StatusCode`, `ResourceAttributes`, and `SpanAttributes`, then writes the target layout.

### Drain Template Handling

`make_rcabench.py` uses Drain3 templates from:

```text
data/rcabench_dataset/drain_template/drain_ts.ini
data/rcabench_dataset/drain_template/drain_ts.bin
```

Rebuild templates only when the raw log corpus changes and you intentionally want to update the source template state:

```bash
uv run python platform/rcabench-platform/cli/dataset_transform/make_rcabench.py build-template
```

For experiments, copy `data/rcabench_dataset/` to a scratch location before rebuilding templates.

### Detector-First Conclusion Flow

`make_rcabench.py` scans only datapacks that have a usable `conclusion.csv`. If `conclusion.csv` is stale or was intentionally removed to force recomputation, run the detector first on the raw datapack, then run the converter.

Single datapack detector flow:

```bash
DATAPACK=ts9-ts-basic-service-response-delay-hfvbg6
uv run python platform/rcabench-platform/cli/detector.py run \
  --in-p data/rcabench_dataset/$DATAPACK \
  --ou-p data/rcabench_dataset/$DATAPACK \
  --convert
```

Batch detector flow over valid datapacks:

```bash
uv run python platform/rcabench-platform/cli/detector.py patch-detection
```

Notes:

- `detector.py run` writes `conclusion.csv` as the legacy detector result file.
- `--convert` additionally writes a `converted/` subfolder for that datapack.
- `make_rcabench.py run` is still the dataset-level conversion path that creates `$DATA_ROOT/data/rcabench` and `$DATA_ROOT/meta/rcabench`.
- Do not delete the committed fixture `conclusion.csv` unless you are intentionally updating data and will commit the regenerated result.

### Convert Raw Data To RCAbench Platform Layout

```bash
DATA_ROOT=temp/rcabench-platform-v2 \
uv run python platform/rcabench-platform/cli/dataset_transform/make_rcabench.py run \
  --parallel 4 \
  --no-skip-finished
```

Expected outputs:

```text
temp/rcabench-platform-v2/data/rcabench/ts9-ts-basic-service-response-delay-hfvbg6/
temp/rcabench-platform-v2/meta/rcabench/index.parquet
temp/rcabench-platform-v2/meta/rcabench/labels.parquet
temp/rcabench-platform-v2/meta/rcabench/attributes.parquet
```

After conversion, use the commands in `docs/extending.md` to run sampler and RCA smoke checks.

## Choosing A Path

| Input | Use path | Recommended first command | Gleaner variant |
|---|---|---|---|
| Legacy TracePicker `traces_spans.csv` only | Path A | `uv run python make_tracepicker.py local-test` | `gleaner_no_logs_no_ad` |
| Raw traces, logs, metrics, env, injection, detector conclusion | Path B | `make_rcabench.py run` | `gleaner` |
| Raw traces/logs/metrics but missing or stale `conclusion.csv` | Path B with detector-first flow | `detector.py run --convert` | `gleaner` |

## Reuse Checklist

- Keep new input conversion in a scratch `DATA_ROOT` until outputs are inspected.
- Verify `meta/<dataset>/index.parquet` and `meta/<dataset>/labels.parquet` exist before running sampling or RCA evaluation.
- Run a cheap `random` sampler and `random` RCA smoke check before running Gleaner or expensive baselines.
- Record the exact `DATA_ROOT`, `OUTPUT_ROOT`, command lines, and generated report paths for any new dataset bundle.
